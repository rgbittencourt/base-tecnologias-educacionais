# Tecnologias Educacionais

Esta é uma base de conhecimento em construção sobre o uso de tecnologia na educação. O objetivo não é promover ferramentas, mas explicar **o que são, para que servem, quais problemas podem resolver e o que as evidências realmente sustentam**.

> [!important] Princípio editorial
> Tecnologia não é uma solução por si só. A escolha deve começar pelo problema educacional, pelo público e pelas condições de implementação.
