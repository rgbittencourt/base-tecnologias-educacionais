# LTI

**Learning Tools Interoperability** é um padrão da 1EdTech para conectar uma ferramenta externa a um [[lms|LMS]] com contexto de usuário, curso e atividade, evitando integrações proprietárias diferentes para cada plataforma.

Versões modernas usam mecanismos de segurança baseados em padrões web e podem apoiar envio de notas e serviços de nomes e papéis.
